# Speed
### A 2D speedrunning platformer where the player can race against the clock on different maps using distinct characters and their unique controls. 

### It's my solo project. Solo here means that all code, as well as all assets - sprites, UI, music, sound effects - are hand made by myself. That also means absolutely no AI.
Exceptions: the code template I used was made by my friend - [Hohenzoler](https://github.com/Hohenzoler); the fonts I'm using originate from a free use website.

## Download tutorial:
1. Open the latest release.
2. Find and download the 'Speed.zip' file.
3. Unzip and open it.
4. Run the 'main.exe' file; you might need to bypass windows defender, which doesn't want you opening it.
